# Über dieses Dokument

> **Hinweis:** Teil des Skripts „AWS Cloud Practitioner (CLF-C02): Lernskript in Modulen“, aus der LaTeX-Quelle in Markdown umgewandelt. Die Kapitel zu den Modulen stehen als `skript.md` in den Modulordnern.

> **Hinweis zum Stand:** Der folgende Text ist unverändert aus der Quelle übernommen. Der Satz „Dieser Stand umfasst die ersten Module; weitere folgen in Etappen“ ist veraltet: Dieses Repository enthält alle zwölf Modulkapitel.

Dieses Skript begleitet die Vorbereitung auf die Prüfung AWS Certified Cloud Practitioner (CLF-C02). Es folgt dem Lehrplan in zwölf Modulen und erklärt jede Lerneinheit zusammenhängend und von Grund auf, sodass keine weiteren Quellen nötig sind, um die Zusammenhänge zu verstehen. Jede Lerneinheit besteht aus erklärender Prosa, einem durchgängigen Beispiel (meist mit der AWS CLI oder einer Richtlinie), typischen Fehlern und einem Praxisbezug. Am Ende jedes Moduls stehen Übungsaufgaben; die Lösungen folgen getrennt dahinter.

Die Module sind nach Priorität gestaffelt erstellt: zuerst alle Module der Priorität 1, danach 2 und 3. Dieser Stand umfasst die ersten Module; weitere folgen in Etappen.

> **Merke**
>
> Inhalt und Beispiele basieren auf dem Lehrplan und auf fachlicher Recherche; es lagen keine eigenen Kursunterlagen vor. Grüne Kästen kennzeichnen Ergänzungen aus der Nachrecherche. Preise, Limits und Servicenamen ändern sich bei AWS laufend; maßgeblich ist immer die offizielle Dokumentation.
