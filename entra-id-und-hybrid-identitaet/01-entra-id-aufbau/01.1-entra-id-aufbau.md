## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| Mandant (Tenant) | eigene Instanz von Entra ID für eine Organisation |
| Standarddomäne | Domäne `….onmicrosoft.com` des Mandanten |
| Verifizierung | Nachweis, dass man eine Domäne besitzt (im Modell über einen DNS-TXT-Eintrag) |
| UPN | Benutzerprinzipalname, Form `name@domäne` |
| Quelle | Cloud oder aus dem lokalen AD synchronisiert |

## Hinweise

- Alle Namen, Domänen und Werte sind erfunden (Domänen mit `.example`/`.test`). Alle Dateien liegen unter `/tmp/p28`. Die Ausgaben stammen vom Modell `entrasim.py`, nicht von Entra ID.
- Die Zeilen „az … ->“ sind echt: Sie zeigen, ob die genannten Parameter im Hilfetext der installierten Azure CLI stehen; sie beweisen nicht, dass etwas im Mandanten funktioniert.
- Die Verifizierung im Modell ist eine Vereinfachung (ein fester TXT-Wert); die Regeln der echten Domänenverifizierung wurden nicht geprüft.

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

1. Siehe `beispiele/aufbau.ausgabe.txt`: Befehlsprüfung für `ad user create`, `ad user list` und `rest`: alle Parameter vorhanden (Azure CLI 2.93.0, nur Hilfetext).
2. Domänen: `labmuster.onmicrosoft.com` verifiziert, `muster-lab.example` NICHT verifiziert.
3. `ana` und `ben` werden mit der Standarddomäne angelegt; `cem@muster-lab.example` scheitert: „Domäne muster-lab.example ist nicht verifiziert; Benutzer können sie nicht als UPN-Suffix verwenden“.
4. `domain verify` mit `MS=falsch` scheitert; mit `MS=ms-erfunden-0001` gelingt es; danach lässt sich `cem` anlegen.
5. Die Liste zeigt UPN, Quelle (alle „Cloud“), Abteilung und eine kurze Objekt-ID (im Modell aus dem Namen berechnet, nicht zufällig).

**Kontrollfragen (Antwortskizzen):**

1. `labmuster.onmicrosoft.com` (verifiziert) und `muster-lab.example` (nicht verifiziert).
2. Die Domäne ist nicht verifiziert (Schritt 3).
3. Die Verifizierung scheitert; das Modell erwartet `MS=ms-erfunden-0001` (Schritt 4).
4. Der Benutzer wurde in der Cloud angelegt, nicht aus einem lokalen AD synchronisiert.

</details>
