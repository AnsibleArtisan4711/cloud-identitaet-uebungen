## 4. Prüfung mit Toleranzfenster: eine Uhr, die nachgeht (echt gerechnet)
$ entrasim mfa verify --secret JBSWY3DPEHPK3PXP --time 1000 --code 475209
Code 475209 bei Zeit 1000: ANGENOMMEN (Schritt 33, Abweichung +0)
$ entrasim mfa verify --secret JBSWY3DPEHPK3PXP --time 1030 --code 475209
Code 475209 bei Zeit 1030: ABGELEHNT (Fenster ±0 Schritte)
$ entrasim mfa verify --secret JBSWY3DPEHPK3PXP --time 1030 --code 475209 --window 1
Code 475209 bei Zeit 1030: ANGENOMMEN (Schritt 33, Abweichung -1)
$ entrasim mfa verify --secret JBSWY3DPEHPK3PXP --time 1090 --code 475209 --window 1
Code 475209 bei Zeit 1090: ABGELEHNT (Fenster ±1 Schritte)

## 5. Lizenzstand (Microsoft Learn, Suchauszug 20.11.2026, nicht die ganze Seite)
Sicherheitsstandards (Security Defaults): für alle Kunden verfügbar, MFA ohne granulare Steuerung.
Bedingter Zugriff (MFA nach Bedarf): erfordert Entra ID P1.
Risikobasierte Richtlinien: erfordern Entra ID P2.
Der Auszug nennt P1 als enthalten in Microsoft 365 E3/E5/F1/F3 und Business Premium; P2 in E5. Aktuelle Pläne vor der Anwendung prüfen.
