## Aufgabe

### Aufgabe 1 – Drei Ringe (Einheit 7.1)

Führen Sie `bash updates.sh` aus. Erklären Sie Schritt 2: Wann wird jedem Ring das Update angeboten und wann spätestens installiert?

### Aufgabe 2 – Pause (Einheit 7.2)

Erklären Sie Schritt 3: Was ändert eine Pause von 10 Tagen?

## Hinweise

- Alle Namen, Seriennummern, Hashes und Werte sind erfunden. Alle Dateien liegen unter `/tmp/p29`. Die Ausgaben stammen vom Modell `intunesim.py`, nicht von Intune.
- Die Zeilen „az … ->“ sind echt: Sie zeigen, ob die genannten Parameter im Hilfetext der installierten Azure CLI stehen; sie beweisen nicht, dass etwas im Mandanten funktioniert.
