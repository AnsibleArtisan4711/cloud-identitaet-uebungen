# Cloud und Identität: Übungen

AWS, Microsoft 365, Azure und Google Cloud. Alles auf Deutsch. Jeder Kurs liegt in einem eigenen Ordner und hat seine eigene README.

| Ordner | Art | Inhalt |
|---|---|---|
| [aws-cloud-practitioner](aws-cloud-practitioner/) | Lernskript | AWS Cloud Practitioner (CLF-C02), 12 Module |

## Lizenz

Die Lizenz gilt je Kursordner und steht dort in der Datei `LICENSE` (Code) bzw. `LICENSE-DOCS.md` (Texte). Der Hinweis in der README des jeweiligen Kurses nennt, welche Lizenz gilt.
